# DevOps Pet Project

A hands-on project for practicing the full path from application code to infrastructure and Kubernetes deployment.

I use this repository to experiment with DevOps workflows, infrastructure configuration, Kubernetes and CI/CD automation.

## Project structure

```text
.
├── .github/
│   └── workflows/       # CI/CD workflows
├── app/                 # application
├── infrastructure/      # infrastructure configuration
└── kubernetes/          # Kubernetes manifests
```

## What I practice here

- working with application and infrastructure code in one project
- Kubernetes deployments and configuration
- CI/CD with GitHub Actions
- infrastructure automation
- Git-based development workflow
- troubleshooting deployment and infrastructure issues

The project is primarily a learning environment where I can test new DevOps tools and practices in a practical way.
